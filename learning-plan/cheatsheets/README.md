# Cheatsheets

Dense, printable reference sheets — one per group of related lessons. They are for
**repetition**, not for learning: everything a lesson taught, compressed to the API surface,
the formulas, the byte layouts and the traps, with no prose to wade through.

Each sheet is a `.md` file here (and, once there are enough, a rendered `.pdf` in `pdf/`).
`[*]` marks a real API or spec detail the lessons have not covered yet — extra surface worth
knowing, kept visually separate from what you have already studied.

> **Nothing here yet.** Sheets get written *after* their lessons. The planned groupings are at
> the bottom of [../PLAN.md](../PLAN.md).
